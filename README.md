# انبار الکترونیک

برنامه‌ی ویندوز برای انبارداری قطعات الکترونیک: موجودی، ورود و خروج، قفسه‌ها و جای دقیق هر قطعه،
پروژه‌ها و BOM، لیست خرید، برچسب و QR، ایمپورت از اکسل و آمار — با اتصال اختیاری به فروشگاه لیون الکترونیک.

![نقشه‌ی قفسه‌ها و جستجو](docs/screenshots/map-search.png)

📘 **[راهنمای کامل امکانات (PDF)](docs/guide.pdf)**

## دانلود و نصب

از بخش [Releases](../../releases/latest) یکی را دانلود کنید:

- **`AnbarElectronic-Setup-x.y.z.exe`** — نصب‌کننده (دسترسی مدیر لازم نیست؛ میانبر منوی استارت و دسکتاپ می‌سازد).
- **`AnbarElectronic-portable.zip`** — بدون نصب؛ باز کنید و `AnbarElectronic.exe` را اجرا کنید.
  اگر کنار exe یک فایل خالی به نام `portable.txt` بگذارید، اطلاعات هم کنار برنامه ذخیره می‌شود (مناسب فلش).

> ویندوز ممکن است هنگام اولین اجرا هشدار SmartScreen بدهد، چون فایل امضای دیجیتال ندارد:
> «More info» و بعد «Run anyway» را بزنید.

اطلاعات هر کاربر ویندوز در `%APPDATA%\AnbarElectronic` است (دیتابیس `warehouse.db` و عکس‌ها) و با حذف برنامه پاک نمی‌شود.
از «تنظیمات › اطلاعات و پشتیبان‌گیری» نسخه‌ی پشتیبان بگیرید یا روی کامپیوتر دیگری بازگردانی کنید.

## امکانات

- **انبار قطعات:** پارت نامبر، توضیحات، دسته، سازنده، پکیج، دیتاشیت، قیمت و تاریخچه‌ی قیمت، حداقل موجودی، عکس.
- **ورود و خروج سریع با کیبورد** (`+` ورود، `−` خروج، `=` شمارش) و تاریخچه‌ی کامل با موجودی قبل و بعد.
- **جستجوی سریع و اسکنر بارکد/QR** روی پارت نامبر، توضیحات، پکیج، سازنده، دسته و کد محل.
- **قفسه‌ها با چیدمان دلخواه** (پایین‌تر را ببینید).
- **پروژه‌ها و BOM:** ایمپورت BOM، کمبود قطعه برای ساخت چند برد، هزینه‌ی هر برد و کسر خودکار از انبار.
- **لیست خرید:** کم‌موجودها و کمبود پروژه‌ها.
- **برچسب و QR** برای قطعه‌ها (چاپگر برچسب یا برگه‌ی A4) و لیبل جلوی کشو و جعبه.
- **ایمپورت از اکسل/CSV** و **آمار** (ارزش انبار، خرید ماهانه، پرمصرف‌ترین‌ها، …).
- **دسته‌بندی دلخواه** با زیردسته، تم روشن و تیره، و میانبرهای صفحه‌کلید برای همه‌ی کارها.

## قفسه‌ها

| | |
|---|---|
| ![کابینت کشویی](docs/screenshots/cabinet.png) | ![قفسه‌ی طبقه‌ای در تم تیره](docs/screenshots/shelf-dark.png) |

- **چهار نوع:** کابینت کشویی، قفسه‌ی طبقه‌ای (جعبه روی طبقه‌ها)، جعبه‌ی خانه‌خانه (ارگانایزر)، جعبه/کارتن تکی.
- **کد مکان:** `شماره‌ی قفسه-ستون‌ردیف-بخش`، مثلاً `3-B4-1` (ستون‌ها از چپ A، B، …؛ ردیف‌ها از بالا).
  هر خانه تا ۳ بخش دارد و با اسکنر QR یا تایپ کد پیدا می‌شود.
- **ادغام خانه‌ها:** Shift+کلیک یا کشیدن موس روی چند خانه، بعد راست‌کلیک › «یکی کردن»؛
  یا در پنجره‌ی خانه «اندازه» را تغییر دهید.
- **نقشه:** «ویرایش چیدمان» → قفسه‌ها را بکشید؛ راست‌کلیک روی جای خالی = افزودن میز، دیوار یا نوشته.
- **ناحیه‌ها:** برای هر اتاق یا انبار یک نقشه‌ی جدا. جستجو در همه‌ی ناحیه‌ها انجام می‌شود.

## اتصال به لیون الکترونیک (اختیاری)

اگر از [لیون الکترونیک](https://lionelectronic.ir) خرید می‌کنید، با روشن کردن این بخش در «تنظیمات» خیلی از کارها خودکار می‌شود.
بدون آن هم برنامه کامل کار می‌کند.

| امکان | توضیح |
|---|---|
| **دریافت سفارش‌ها** | سفارش‌ها از حساب کاربری شما خوانده می‌شوند — دستی (`F5`) یا خودکار هر ۱۵ دقیقه تا ۳ ساعت. |
| **ورود به انبار با تأیید شما** | سفارش جدید خودکار وارد موجودی نمی‌شود؛ خودتان انتخاب می‌کنید کدام وارد شود. «لغو ورود» هم دارد. |
| **ساخت خودکار قطعه‌ها** | قطعه‌های جدید سفارش با پارت نامبر، توضیحات، قیمت و لینک ساخته می‌شوند و موجودی بقیه بالا می‌رود. |
| **تاریخچه‌ی قیمت** | قیمت هر قلم از هر سفارش در تاریخچه‌ی قیمت قطعه ثبت می‌شود. |
| **تکمیل اطلاعات قطعه** | دسته، سازنده، پکیج، دیتاشیت، مشخصات فنی، عکس و قیمت از صفحه‌ی محصول؛ برای قطعه‌ی بدون لینک با پارت نامبر در سایت جستجو می‌شود. |
| **دسته‌بندی سایت** | درخت سه‌سطحی دسته‌های لیون وارد برنامه می‌شود و دسته‌ی هر قطعه خودکار تشخیص داده می‌شود. |
| **تطبیق قطعه‌های عمومی** | مقاومت، خازن، سلف، کریستال، LED و فیوز بر اساس مقدار، پکیج، تلرانس و ولتاژ با محصولات لیون تطبیق داده می‌شوند (بین چند گزینه، ارزان‌ترین). |
| **سبد خرید** | اقلام لیست خرید با یک دکمه به سبد خرید حساب شما در سایت اضافه می‌شوند (با رعایت حداقل سفارش). |
| **لیست خرید هوشمند** | با ورود سفارش، اقلامش خودکار از لیست خرید حذف می‌شوند. |
| **آمار خرید** | نمودار خرید ماهانه از لیون و جمع خریدها. |

اطلاعات ورود فقط روی همان کامپیوتر ذخیره می‌شود. تکمیل اطلاعات و قیمت قطعه‌ها بدون حساب کاربری هم کار می‌کند.

## اجرا از سورس

پایتون ۳.۱۱ یا جدیدتر:

```
pip install -r requirements.txt
python main.py
```

ساخت exe و نصب‌کننده: `build.bat` (برای نصب‌کننده، [Inno Setup 6](https://jrsoftware.org/isdl.php) لازم است).
